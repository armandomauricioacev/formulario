# Documentación del Proyecto: Solicitud de Servicios IMT

Este proyecto es una aplicación Laravel para gestionar solicitudes de servicios del IMT.

Contenido principal:
- Arquitectura general y componentes.
- Rutas y controladores.
- Modelos Eloquent y estructura de datos.
- Manejo de errores y transacciones.
- Activos front-end (Vite/Tailwind) y recursos.
- Instalación y configuración.

La documentación describe el funcionamiento existente sin modificar la lógica, funcionalidad ni diseño.
